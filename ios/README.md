# Sonalex — the app (SwiftUI, iPhone, iPad, Mac)

A native app that plays the music library of a Jellyfin server: home, new releases, library,
search, full-screen player with synced lyrics, queue, offline downloads, AirPlay, lock screen,
Dynamic Island, and a real Mac app (Mac Catalyst) with a sidebar and a menu bar icon.

With the [Sonalex server](../backend/README.md) next to Jellyfin: Mix (DJ transitions) and
Connect (one device plays, the others control it). The app detects it on its own
(`ServerFeatures`, `GET <jellyfin>/sonalex/api/health`) and only shows what it offers.

## Building

Requirements: a Mac with **Xcode 26** or later, iOS 18+ on the device, and
[XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).

```bash
cd ios && xcodegen && open Sonalex.xcodeproj
```

1. **Xcode → Settings → Accounts → +**: add your Apple ID.
2. Target **Sonalex → Signing & Capabilities**: pick your team. The `com.alexgarin.sonalex`
   identifier belongs to the App Store app: replace the `com.alexgarin` prefix in `project.yml`
   (`bundleIdPrefix` and both `PRODUCT_BUNDLE_IDENTIFIER`), then run `xcodegen` again.
3. Plug in the iPhone, turn on **Developer Mode** (Settings → Privacy & Security), then ▶.
   The first time: **Settings → General → VPN & Device Management → Trust**.

> With a free Apple ID, the app **expires after 7 days**: run ▶ from Xcode again.

`Sonalex.xcodeproj` is generated from `project.yml` and isn't versioned: run `xcodegen` again
after adding or removing files.

## On the Mac

Destination **My Mac (Mac Catalyst)**, then ▶. After each Mac build, the app is installed in
**Applications** and registered for `sonalex://` links (`scripts/install-mac-app.sh`).

- Shortcuts: space, ⌘← / ⌘→, ⌘S (shuffle), ⌘R (repeat), ⇧⌘L (now playing).
- Can be controlled by other apps (Atoll…): `open -g "sonalex://pause"` (`musique://` works too),
  or a command file + a Darwin notification: [`docs/now-playing-mac.md`](../docs/now-playing-mac.md).
- **App Store version**: the *Release* configuration turns on the App Sandbox
  (`Sonalex/Sonalex-mac.entitlements`), required on the Mac App Store. In the sandbox,
  `NowPlaying.json` is written inside the app's container; *Debug* builds keep the usual folder.

The `sonalex://` scheme is declared in `project.yml` and in `Sonalex/Info.plist`, generated by
`xcodegen` and committed: both must stay identical (the build fails otherwise).

## Architecture

| Folder | Contents |
|---|---|
| `Sonalex/API` | `JellyfinClient` (Jellyfin REST), `SonalexAPI` + `ServerFeatures` (Sonalex server), `ResponseCache` (disk cache of responses), models, session |
| `Sonalex/Player` | `PlayerManager` (`AVQueuePlayer`, gapless, background, lock screen, persisted queue), `MixEngine` (AVAudioEngine: the Mix pieces back to back), `ConnectManager`, `OfflineStore` (downloads), `NowPlayingExport` (Mac) |
| `Sonalex/App` | entry point, tabs (iPhone) and Mac window, routing, stores (favorites, images, toasts), `AppInfo` |
| `Sonalex/Ambilight` | Ambilight lights of a Mac on the network: Bonjour discovery, pairing, live audio streaming |
| `Sonalex/Views` | the screens |
| `SonalexMenuBar` | the Mac menu bar icon (AppKit plug-in, loaded by the Catalyst app) |
| `Sonalex/Resources` | icons, accent color, `PrivacyInfo.xcprivacy` |
